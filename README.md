# Autonomous Pica Mechanism Research

An iterative biomedical literature-research protocol for Gemini to investigate the biological mechanism of Pica.

## Goal

Go beyond summarizing the Pica literature. Build a mechanistic evidence graph, connect Pica to adjacent biological fields, actively search for contradictions, identify missing causal links, and generate falsifiable hypotheses.

## Core loop

`discover → extract → citation-expand → connect → identify gaps → hypothesize → falsify → novelty-check → design experiment → search again`

## Initial intersections

- Pica × iron deficiency / iron biology
- Pica × nutrient-specific appetite
- Pica × gut-brain signaling
- Geophagy × gastrointestinal inflammation
- Geophagy × microbiome
- Pica × vagal signaling
- Pica × interoception
- Iron × dopamine/reward circuitry
- Substance-specific Pica phenotypes
- Human Pica × animal geophagy/mineral seeking

See `GEMINI.md` for the complete research protocol.
